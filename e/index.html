Projects

Customizable High-Efficiency Memory–File Mapping on Linux

2018–2019

Undergraduate thesis project. Built a user-space memory–file mapping runtime on Linux using the userfaultfd system call to overcome mmap limitations (write-back policies, unified page management, fixed swap granularity). Achieved up to 25% speedup over mmap on sequential workloads and 23–84% end-to-end improvements on real applications.

JudgeDuck OS

Repository, Live Demo2018

Operating system designed for precise and stable measurement of program runtime and memory usage, delivering at least 5× higher stability than Linux for programming contests. Powers the Judge Duck Online OJ. I contributed to the core design and early implementation.
